# 判定の手順(Claudeが1日1回やる)

点数の表(スターの活躍など)は機械的なので、表にない種類のすごさ(年齢・節目・万能の活躍・決め方など)は拾えない。
そこで持ち主(ユーザー)がアプリの「👑 持ち主の判定」でランクを直すと、それが**判例**として `scripts/judgments.json` に残る。
Claudeは毎日その判例を読み、**似たすごさの試合を、持ち主に聞かずに上げる**。持ち主があとから直したら、それも記録になる(=次に活かす)。
持ち主の方針:「覚えられないなら意味がない。同じような条件が来たら、聞かずに対応できるようにする」

軽く済ませること(持ち主の利用枠を使うので)。仕様メモ全体やコード全体は読まない。

## 手順
1. リポジトリ `tak0913/nba-navi` を push できる形で用意してクローンする(main)。
2. `cd scripts && python3 tests/run_tests.py`(失敗したら何も書かずに終わり、失敗したと報告)。
3. `OUT_DIR=../docs python3 collect.py --rebuild --no-buzz`(1〜2分)。
4. `python3 ../tools/judge_material.py` を読む。あわせて `scripts/lessons.json` の `lesson` も読む。
   - **判例が0件なら、ここで終わり**(判定しない。記録だけ 8 で残す)。持ち主の感覚がまだないのに、Claudeの好みで上げない。
5. 「まだ判定していない試合」を1試合ずつ、判例とくらべる。`scripts/claude_judge.json` の `claude` に1試合1件足す(前の分は消さない・書き換えない):
   - **上げる**:`"試合id": {"to": 上げた先, "why": 理由, "like": [似ている判例のid], "at": 今日}`
     - 判例と**同じ種類のすごさ**(何がすごかった?の種類+様子)がはっきりあるときだけ。迷ったら上げない
     - 今の計算より上だけ。**1段まで**(C→B など)。持ち主が判定した試合はさわらない
     - 「直された記録」に似た間違いがあるなら、同じ間違いをしない
   - **上げない**と決めたけど判例に近かった試合:`{"to": null, "why": "上げない理由(短く)", "like": [...], "at": 今日}`(次に活かすため)
   - 判例とまったく関係ない試合は書かない
   - 理由(why)… 150字まで。**最終スコアと勝ち負けは書かない**。材料にある数字と事実だけ(選手の年齢・通算の節目のような変わらない事実は、確かなときだけ使ってよい。迷ったら使わない)。何が判例と似ているかを言う。むずかしい言葉を使わない。選手名は英語のフルネーム
6. 「ルールにする候補」が出ていたら、`claude_judge.json` の `rules` に1件足す:
   `{"tags": [種類], "cases": [判例のid], "text": 点数の決まりにするならどうするか(例:38歳以上のスターが◯◯なら+◯点)と、メリット・デメリット, "status": "proposed", "at": 今日}`
   決めるのは持ち主。勝手に config や collect.py は変えない。
7. `python3 ../tools/judge_check.py` が OK になるまで直す。
8. `scripts/writer_log.json` の `runs` に1件足す:`{"date": 今日, "by": "定期のClaude(判定)", "written": 上げた試合数, "note": 気づいたこと(短く)}`
9. `scripts/claude_judge.json` と `scripts/writer_log.json` だけをコミットして main に push(`git pull --rebase origin main` してから)。コミットの文は「判定を更新(◯試合)」。ほかのファイルは変えない。
10. 最後に一言だけ報告:上げた試合数、ルールにする提案を出したか、push できたか。**試合の中身(スコア・勝敗・誰が活躍したか・どの試合を上げたか)は報告に書かない**(持ち主の推しはロケッツで、ネタバレ禁止)。ルールの提案を出したときだけ、PushNotification で「判定のルールの提案があるよ」とだけ知らせる。

うまくいかないとき(リポジトリに書き込めない・ESPNに届かない・テスト失敗)は、無理に回り道をせず、何が起きたかだけ報告して終わる。
