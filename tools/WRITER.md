# 言葉を書く手順(Claudeが1日1回やる)

終わった試合の「見方の一言」と「理由」を、Claudeが試合ごとに言葉を選んで書き、`scripts/lines.json` に保存する。
持ち主(ユーザー)の方針:「持ち合わせの言葉を当てるだけにしない。必ずClaudeが言葉を選ぶ。毎回同じ言葉にしない。誰が活躍したかだけでなく、なぜ爆発したのかまで書く」「ズレや投稿を今回限りで終わらせず、次の試合に活かす」

軽く済ませること(持ち主の利用枠を使うので)。仕様メモ全体やコード全体は読まない。読むのは下の3つだけ。

## 手順
1. リポジトリ `tak0913/nba-navi` を push できる形で用意してクローンする(main)。
2. `cd scripts && python3 tests/run_tests.py`(失敗したら何も書かずに終わり、失敗したと報告)。
3. `OUT_DIR=../docs python3 collect.py --rebuild --no-buzz`(1〜2分。`scripts/material.json` ができる)。
4. 読む(この3つだけ):
   - `python3 ../tools/lines_material.py` … まだ言葉がない試合の材料。0試合なら 7 へ(記録だけ残す)
   - `python3 ../tools/lines_material.py --recent` … 最近書いた言葉(同じ言い回しを続けないため)
   - `scripts/lessons.json` … ズレの台帳(投稿・指摘から学んだこと)。`lesson` を今日の言葉に活かす
5. `scripts/lines.json` に、材料に出た試合ぶんを足す(前からある分は消さない・書き換えない)。
   形:`"試合id": {"k": 材料の「見方の種類」そのまま, "at": "今日の日付", "guide": "見方の一言", "why": "理由"}`
6. `python3 ../tools/lines_check.py` が OK になるまで直す。
7. `scripts/writer_log.json` の `runs` に1件足す:`{"date": 今日, "by": "定期のClaude", "written": 書いた試合数, "note": 気づいたこと(短く。なければ空)}`
8. `scripts/lines.json` と `scripts/writer_log.json` だけをコミットして main に push(`git pull --rebase origin main` してから)。
   ほかのファイルは変えない。コミットの文は「言葉を更新(◯試合)」。
9. 最後に一言だけ報告:書いた試合数、push できたか。**試合の中身(スコア・勝敗・誰が活躍したか)は報告に書かない**(持ち主の推しはロケッツで、ネタバレ禁止)。

うまくいかないとき(リポジトリに書き込めない・ESPNに届かない・テスト失敗)は、無理に回り道をせず、何が起きたかだけ報告して終わる。

## 書き方の決まり
### 見方の一言(guide)… 60字まで
- 中身は材料の「見方の種類」どおりにする。変えていいのは言い回しだけ。
  - `full_comeback` 最初から全部(約2時間15分)。逆転の流れごと見てほしい
  - `full_or_q4` 最初から全部(約2時間15分)。時間がなければ第4Qから(約40分)
  - `full` 最初から全部(約2時間15分)
  - `q4` 第4Qから(約40分)
  - `half` 後半から(約1時間10分)
  - `hl_star` フルハイライト(約10分)で十分。スターの見せ場はそこに入っている
  - `hl` フルハイライト(約10分)で十分
  - `skip` 見なくてもいいかも。気になるならハイライト
- どこから見るか(と、だいたいの時間)は必ず入れる。
- **選手名・点数・スコア・勝ち負け・点差は書かない**(スコアと勝敗を出さない段に出るため)。決まり文句より多くのことがわかる言い方もしない(「大差」「一方的」など)。
- 同じ日の中で同じ文を使わない。最近書いた言葉とも、できるだけ変える。

### 理由(why)… 150字まで
- 材料にある数字と事実だけで書く。材料にないこと(調子・気持ち・作戦・ケガの具合など)は推測なので書かない。
- 「誰が何点」だけで終わらせない。**なぜ・どう爆発したか**を材料から言う。使えるもの:
  - Qごとの得点(「第4Qだけで15点」「後半だけで30点」)
  - シュートの内訳(「3Pが8本中5本」「シュート9本を全部決めた」「フリースローで10点」)
  - 出場時間(「24分の出場で29点」)
  - 相手・味方の欠場(「エース欠場の中で」)、チームの出来(「守備がいつもより良かった」)
- 得点以外の活躍も拾う:あと1〜2個でトリプルダブル、スティール・ブロックが多い、アシストが多い。
- 展開(接戦・延長・逆転・ブザービーター)があれば先に書く。
- **最終スコアと、どちらが勝ったかは書かない**。
- 選手・HCの名前は英語のフルネーム(カタカナにしない)。チームは略称(HOU など)。
- むずかしい言葉を使わない。使うなら意味がわかる言い方にする(例:TO → ボールを失った回数)。
- 文の形を毎回変える。同じ言い回し(「〜の高効率の30点超え」など)を続けない。
